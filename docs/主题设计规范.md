## 约束

- 所有主题使用同一业务组件与事件，不改变菜单流程、任务转换、手动发布、自动化、模型或 MCP 行为。
- 装饰不含 slogan，不包含文字，不遮挡内容或鼠标事件。
- `public/brand/fish.svg` 是唯一 Logo 母版。侧栏和主题缩略图直接引用；打包前 `scripts/sync-brand.cjs` 同步浏览器图标和 macOS 图标。
- `visual-themes.ts` 是主题目录及色彩变量来源；`studio-signatures.css` 定义各套形态、材质与布局。新增主题需明确用户授权。
- 账号、素材、API、Skill 和所有个人数据与主题无关，不进入安装包。
- 尊重系统减少动态效果设置。

## 本轮验证

- 8 个主题均通过真实主题菜单切换；详情颜色、导航宽度及画廊列宽分别核验。
- 8 个主题账号表单均可打开，抽屉处于正确顶层。

- 任务行点击打开只读视图，编辑按钮打开编辑表单。
- 21 项原有自动化测试通过；生产构建及类型检查通过。
