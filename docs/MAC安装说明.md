# 自媒体工作台 · Mac Apple Silicon 测试版

适用于 M 系列芯片 Mac，macOS 13 或更高版本。

## 安装与启动

1. 打开 `SelfMediaWorkbench-0.1.5-mac-arm64.dmg`。
2. 将「自媒体工作台」拖入 Applications（应用程序）。
3. 从应用程序或 Dock 打开，无需浏览器、Node.js 或终端。

当前为本地测试版，使用临时签名，尚未进行 Apple Developer ID 签名和公证。对外分发前需补齐签名与公证。如系统拦截，请通过 macOS「隐私与安全性」查看对应提示；不要关闭系统整体安全保护。

## 首次使用

首次打开为空白工作空间。点击左侧「账号工作区」旁的设置图标，添加运营账号，然后创建内容。模型、Skill、素材、MCP 均需自行配置。未调用真实模型的空白安装不需要 API Key。

## 数据和运行

- 个人数据位于 `~/Library/Application Support/SelfMediaWorkbench/data`，与安装包分离。
- 日志位于同目录下的 `logs`。应用菜单提供「打开数据目录」和「打开日志目录」。
- API Key 使用加密文件保存，加密主密钥由 macOS 钥匙串保护。升级仅替换 App，不覆盖用户目录。
- MCP 默认关闭，无预置客户端和隧道；启用后在 AI 配置中复制本机地址及独立凭证。
- 关闭窗口会隐藏到后台，点击 Dock 可重新打开；Command-Q 才会退出并停止本地服务。
- 自动化需要 App 持续运行及电脑保持唤醒；本版不提供系统开机自启或自动更新。
- 平台发布仍需手动操作。Skill 文本流程已接入模型；第三方脚本运行、云端隧道连接需要相应能力与配置，并非安装后自动具备。

## 备份

工作台内「备份与恢复」导出内容、账号及支持的附件，不导出模型密钥和 MCP 授权。更换 Mac 后重新配置密钥。卸载 App 不主动删除个人数据目录。
